# Данные организатора

Сюда кладется `catalog_export_v4.csv`, выгрузка каталога роботизированных решений ФЦ БАС, которую организатор хакатона выдал участникам вместе с датасетами. В открытом репозитории файла нет: по условию материалы организатора нельзя публиковать.

Если файл лежит здесь, сервис при первом запуске загружает его в базу той же загрузкой, что кнопка в админке, и в каталоге 190 позиций (дубли с тем же номером и ценой склеены). Без файла сервис работает на нашем каталоге из 31 решения, а выгрузку администратор загружает кнопкой в админке.

Правила склейки дублей и привязки к объектам описаны в docs/decisions.md, разделы "Дубли каталога склеиваем по номеру и цене" и "Цена робота берется из каталога, каталог выгружается и загружается обратно".
