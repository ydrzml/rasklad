# Параметры объектов

Аэропорт и медучреждение по ТЗ доводим до выбора объекта, параметров и списка решений (п. 5.5). Здесь лежат параметры этих объектов и список решений для них. Склад описан в `config/model.yaml` и `config/parameters.yaml`, потому что по нему идет полный расчет.

## Файлы

| Файл | Что внутри |
|---|---|
| `airport.csv` | 39 параметров аэропорта |
| `clinic.csv` | 57 параметров многопрофильной больницы |
| `tasks.csv` | Задачи объекта на первом шаге: какой параметр датасета показываем объемом и чью численность |
| `solutions.csv` | Какие решения подходят аэропорту и медучреждению, под какую задачу и почему |

Характеристики самих решений хранятся вместе со складскими в `data/specs/sources.csv` и `data/specs/specs.csv`.

## Формат airport.csv и clinic.csv

Разделитель `;`, кодировка UTF-8. Одна строка это один параметр.

| Поле | Что это | Пример |
|---|---|---|
| `section` | Раздел листа датасета | Пассажирский поток |
| `key` | Короткое имя параметра латиницей, по нему параметр найдет код | `passengers_peak_hour` |
| `name` | Название как в датасете | Пиковое количество пассажиров в час (PHF) |
| `unit` | Единица измерения | пасс./ч |
| `value` | Базовое значение, типичный объект для демо | 3200 |
| `min`, `max` | Допустимый диапазон, за ним форма предупреждает. Пусто, если параметр не числовой | 200, 18000 |
| `note` | Примечание организатора как есть | |
| `source` | Откуда значение | Датасеты_хакатон.xlsx, лист "Аэропорт" |
| `source_type` | Тип источника по [правилам данных](../../docs/data-sources.md) | организатор |
| `retrieved` | Когда получили | 2026-09-15 |
| `rating` | Оценка достоверности | D |
| `check` | Что мы проверили сами и что не сошлось | |

Все значения пока из одного источника, файла организатора, поэтому у всех оценка D. В легенде датасета указано откуда организатор их брал: для аэропорта Росавиация, ИКАО doc 9137, публичный отчет Шереметьево и IATA, для медучреждения Минздрав, СанПиН 2.1.3.2630-10, СанПиН 2.1.3684-21, ГОСТ Р 53079 и опыт внедрений Aethon и Swisslog. Какая цифра из какого документа, не сказано, поэтому ссылку на первоисточник мы не ставим.

## Формат tasks.csv

| Поле | Что это |
|---|---|
| `facility` | `airport` или `clinic` |
| `operation` | Задача объекта, название берется из справочника задач админки |
| `volume_key` | Какой параметр листа стоит в строке задачи крупным числом |
| `staff_keys` | Параметры численности из листа, через запятую. Пусто, если датасет не говорит, кто это делает |
| `description` | Что робот в задаче делает, одной строкой |

Своей численности и выработки мы тут не придумываем: расчетной модели у этих объектов нет, и строка задачи показывает только то, что есть в датасете.

## Формат solutions.csv

Одна строка это одно решение для одного объекта. Уборщики из каталога встречаются дважды, для аэропорта и для больницы.

| Поле | Что это |
|---|---|
| `facility` | `airport` или `clinic` |
| `catalog_id` | Номер из каталога организатора или `ext-название` для решений не из каталога |
| `product` | Название как в `data/specs/sources.csv` |
| `source` | Откуда решение: каталог организатора или открытые источники |
| `operation` | Задача объекта, как в админке каталога: `baggage_transport`, `floor_delivery` и другие |
| `process` | Что именно робот делает, словами |
| `why` | Почему взяли, коротко и с фактом из источника |
| `limits` | Чего не хватает и что мешает |
| `status` | Статус из каталога или можно ли купить в России |

Для аэропорта 12 решений: 6 из каталога и 6 из открытых источников. Для медучреждения 18: 10 из каталога, из них 6 уборщиков, и 8 из открытых источников. Как выбирали, записано в [журнале решений](../../docs/decisions.md), раздел "Решения для аэропорта и медучреждения: каталог плюс открытые источники".

## Что не сошлось

Мы пересчитали цифры датасета друг через друга. Расхождения записаны в поле `check`, главные:

- Клиника, порции питания. В примечании формула "коек * занятость * кратность", это 650 * 0,82 * 3 = 1 599. В датасете 1 950, то есть без учета занятости. Разница 22%.
- Аэропорт, заправки. Указано 280 в сутки, столько же, сколько взлетов и посадок вместе. Заправляют только вылетающие рейсы, их вдвое меньше.
- Аэропорт, багаж. 35 000 мест в сутки на 23 300 пассажиров, это 1,5 места на пассажира. Откуда такая доля, в датасете не сказано.
- Коэффициент начислений 1,302 взят как у склада. Для склада мы уточнили тариф на травматизм по ОКВЭД, для аэропорта и больницы еще нет.
