# Изменения после первой сдачи 30.09.2026

Здесь то, что поменялось в сервисе с первой сдачи. Подробности и причины решений в [docs/decisions.md](docs/decisions.md).

## Финал (20.10.2026)

### Подбор

- Штучный отбор всегда считается по робозоне на части склада, станция отбора обязательна, остальные задачи идут по плану с людьми.
- Объем отбора берется от штата и строки датасета, под выбором стоит строка "что нужно, чтобы окупилось".
- Роботы с подъемом подходят при условии, а не отсекаются: решение, которое поднимает груз впритык, идет после решений с запасом и помечено "на пределе".
- Сортировка по цене на шаге 4, способы оплаты видны рядом с каждым решением.
- Ноль роботов считается без вложений и без высвобождения людей.

### Смена на плане

- Все задачи объекта идут на одном плане вместе, парк может быть смешанным.
- Режим склада по умолчанию типовой (две смены по 8 часов, 250 рабочих дней), режим без выходных выбирается отдельно.
- Чертеж DXF работает как подложка под план склада: разбор по слоям (здание, ряды, ворота), файлы до 80 МБ, понятные отказы.
- Чертеж: одно окно при входе, окно свойств поверх листа, копирование и вставка, горячие клавиши, обучение по карточкам.
- Станции отбора на типовой робозоне, уборка роботом ночью.

### Экономика

- Итог по своему выбору: покупка, аренда, лизинг или кредит против работы без роботов, с одним переключателем сценария.
- План на 5 лет по годам, окупаемость по формуле ТЗ рядом с окупаемостью по потоку, ROI одной строкой в процентах.
- Срок службы робота считается отдельно от срока амортизации, окупаемость может быть дольше горизонта.
- Аренда считается как найм без выкупа, выкуп показан отдельным кейсом.
- Штат реалистичнее: присмотр за роботами долями поста, закрытые вакансии не деньги, люди в смене целыми, учтены НДС, связь и постоянные вложения.
- Страница "Как читается экономика" и методика статьей: формулы, обозначения, источники.

### Медучреждение

- План корпуса по этажам в мастере, смена на плане корпуса с лифтами и очередями, итог на своем корпусе.
- Роботы, которые не подходят корпусу, отсекаются с причиной, у каждой цифры есть источник и дата.
- Отчет PDF и таблицы Excel, итог устроен так же, как у склада, окупаемость считается за то же время, за которое платим.
- Поиск парка отвечает за 20 секунд.

### Разборы реальных кейсов

- Готовые разборы для гостя на `/cases`: крупные числа сверху, смена по кругу, способы оплаты рядом.
- Разборы повторяют реальные внедрения, числа на всех шагах сходятся и приходят с сервера.
- Расчет сверен с реальными складами, по итогам поправлены режим, штат и доля работы водителя.
- Каталог роботов для гостя на `/catalog`.

### Интерфейс

- Шаги 1, 2, 4 и 5 проще: меньше текста, блоки и иерархия, один главный ответ сверху, подробности раскрываются списком строк.
- Главные экраны и кабинет на словах пользователя, выбранный вариант лендинга стал главной страницей, темная тема мягче.
- Кабинет: решение в сравнении, разные названия проектов, отчет по сохраненной версии из сохраненных цифр.
- Восстановление пароля и подтверждение почты при регистрации.

### Надежность

- Шаг 5 отвечает на нажатие за секунды, остальное досчитывается после ответа.
- Понятные отказы словами вместо голых кодов 413 и 422.
- Эталонные расчеты и сходимость цифр закреплены тестами, проверки идут на каждый pull request.
- Документация, пример отчета и стенд обновлены под все изменения.
